# 共享语音契约（media.h）

> 语音类型与传输属性的唯一定义处——**纯头文件：没有实现、没有进程、不占模块号**。03（线格式搬运）、05（设备参数）、06（语音前端 / ASR / TTS）、M2（选路与编排）共同引用。**定义权在此，解释权在 06/M2**；传输层只搬运、不解释。

## 为什么单独立契约

- 03 与 05 各自定义一份音频参数会漂移（`AudioFormat` vs 语音块元数据），改一处漏一处。
- 语音语义（`is_final`/`sequence` 的含义）不属于传输层；契约集中后，03/05 只认"类型 + 传输属性"，不再认识"语音"本身。
- 不立模块/进程：语音没有独立进程的必要（不碰内核阻塞，时延预算紧，多一跳纯亏损）；算法归 06 的语音前端，选路/混音归 M2。

## 契约（media.h）

```cpp
// ===== media.h：共享语音契约（纯头文件：03 / 05 / 06 / M2 共同可见） =====

struct AudioFormat {          // 音频参数：05 设备侧与 06 语音前端共用
    uint32_t sample_rate;     // Hz
    uint16_t channels;
    uint16_t bits_per_sample;
    uint32_t period_frames;   // 一拍帧数：流式时延预算粒度
};

struct VoiceMeta {            // 语音元数据：终端线格式的 JSON 字段；03 只搬运不解释
    uint32_t sample_rate;     // Hz
    uint16_t channels;
    uint16_t bits_per_sample;
    uint32_t sequence;        // 分块序号，从 0 开始
    uint8_t  is_final;        // 整句结束标志（非块结束标志）：含义归 06/M2
};

// 大块负载的种类（不透明编号）：语义由生产与消费双方约定，传输层不解释。
constexpr uint32_t kKindVoicePcm = 1;   // 终端语音：负载 = 语音头 + 裸 PCM

// 背压归属：由块的生产者声明，传输层按声明执行，不按类型猜。
constexpr uint8_t kQosCritical = 1;     // 关键：阻塞投递方，不许丢（控制、回执）
constexpr uint8_t kQosRealtime = 2;     // 实时：丢旧留新 + 计数（语音、视频）
```

## 引用关系

| 使用方 | 引用 | 怎么用 |
|---|---|---|
| 03 网络 | `VoiceMeta`、`kKind*`、`kQos*` | 线格式解析时搬运元数据；大块按 `kind`/`qos` 打包上环，不解释 |
| 05 设备 IO | `AudioFormat` | 流式设备参数（`dev.h` 直接引用，不重复定义） |
| 06 AI | 全部 | 语音前端：重采样/声道混合/VAD/整句切分；解释 `sequence`/`is_final` |
| M2 业务 | 全部 | 选路（终端/本地）、混音、会话节奏 |

## 块布局（02 数据面）

大块负载在 02 环上的统一布局（03 的 `NetBulkBlock` 即此形）：

```
[定长头：peer / kind / qos / payload_len]
[不透明负载：payload_len 字节]
```

- `kind = kKindVoicePcm` 时，负载 = 语音头 + 裸 PCM：语音头按**定长二进制编码**（不含 `std::string`、不依赖 ABI，逐字段写入），消费方按 `kind` 解析。
- 块大小受 02 环槽位上限约束：写入方超限直接拒绝，不截断。

## 规则

- **定义权**：音频参数、语音元数据、块 kind、qos 只在这里定义；其它模块引用，不复制。
- **解释权**：`is_final`/`sequence`/采样参数的含义归 06（语音前端）与 M2（选路/节奏）；03/05/02 只搬运，不做分支判断。
- **QoS 声明制**：生产者声明 `kQosCritical`/`kQosRealtime`；传输层（02 环、03 出站、05 音频）按声明执行背压，不按类型猜。新增数据类型必须声明 qos——与 [policy.md](policy.md) 的事件行同一精神：**声明即注册**，块声明带 qos 由编译期审查。
- **演进**：新增媒体类型 = 加一个 `kKind*` 常量，不动传输契约；新增语音字段 = 只动本文件与线格式编码，不动 02/05。
- **不是模块**：无类、无实现、无进程、无号段；不参与模块编号（01–07）与状态表。
